# TasksTODO

A task / to-do management application for creating, tracking, and completing tasks.


## Features

- Create, edit, complete, and delete tasks 
- Organize tasks by status or priority
- Persist tasks between sessions 


## Getting started

```bash
git clone https://github.com/MoayadHamza/TasksTODO.git
cd TasksTODO
mvn clean package
java -jar target/TasksTODO.jar
```
